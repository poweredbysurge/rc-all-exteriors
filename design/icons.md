# icons.md · RC All Exteriors Mode A

Lucide (ISC), stroke 1.75px, round caps and joins. Sizes: 20px inline in trust bars, buttons and the sticky bar; 24px default; 32px on service cards, icon cards, callouts and photo-gap blocks. Color: `--color-accent` on light surfaces, `--icon-on-dark` (white at 90%) on `--color-surface-contrast`. Never inside a circle or a filled square. The artboards carry redrawn paths; code installs the `lucide` package and uses these names.
